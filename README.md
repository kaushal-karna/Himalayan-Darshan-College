# Himalaya Darshan College Website

A modern, responsive, and premium web application for **Himalaya Darshan College**, Biratnagar. This project features a sophisticated "Indigo & Gold" design system, glassmorphic UI components, and a mobile-first approach.

## 🚀 Features

- **Premium UI/UX Overhaul**: Sophisticated design using a custom "Indigo & Gold" color palette.
- **Glassmorphic Design**: Modern components with `backdrop-filter` effects.
- **Responsive Navigation**: Sticky header with a functional mobile hamburger menu.
- **Professional Forms**: Multi-column, structured forms for Admissions and CMAT Registration.
- **Site-wide Consistency**: Unified header and footer across all 7 pages.
- **SEO Optimized**: Semantic HTML and refined meta tags for better search visibility.
- **Interactive Elements**: Hero section animations, gallery hover effects, and smooth transitions.

## 🛠️ Tech Stack

- **HTML5**: Semantic structure.
- **Vanilla CSS3**: Custom properties, Glassmorphism, and responsive Grid/Flexbox layouts.
- **JavaScript**: Slider functionality, mobile menu toggle, and UI interactions.
- **Font Awesome**: Premium iconography.
- **Google Fonts**: 'Outfit' and 'Inter' for modern typography.

## 📄 Pages Included

1. `index.html` - Home page with Hero, Programs, About, and Testimonials.
2. `registeration.html` - Comprehensive Admission Form.
3. `cmat.html` - CMAT Registration Gateway.
4. `gallery.html` - Visual journey of the college.
5. `contactus.html` - Contact details and message form with Google Maps.
6. `login.html` - Student/Admin login portal.
7. `signup.html` - Account creation portal.

## 🖥️ Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/kaushal-karna/Himalayan-Darshan-College.git
   ```
2. Open `index.html` in your favorite browser.
